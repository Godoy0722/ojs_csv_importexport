# OJS CSV Import Plugin

This plugin allows administrators to import users and issues with their associated metadata in CSV format into OJS 3.4.X. It supports both a web interface (GUI) and a command-line interface (CLI).

## Documentation

Documentation for this plugin is maintained in a separate repository. [Click here to see the docs](https://github.com/Godoy0722/csvImportPluginDocs).

That repository covers the web interface, CLI usage, CSV format, multi-locale support, article versions, supplementary files, dry mode, and troubleshooting.
